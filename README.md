# Todo Web Application

A responsive, interactive Todo web application built with HTML, CSS, and JavaScript. Features full CRUD (Create, Read, Update, Delete) functionality.

## 🚀 Live Demo

[View Live on Netlify](https://your-app-name.netlify.app) <!-- Add your Netlify link here after deployment -->

## ✨ Features

- ✅ Add new todos
- 📝 Mark todos as complete/incomplete
- 🗑️ Delete todos
- 💾 Local storage persistence
- 📱 Fully responsive design
- 🎨 Modern glass-morphism UI

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
- Local Storage API

## 🎯 CRUD Operations

- **Create**: Add new todo items
- **Read**: Display all todos in a list
- **Update**: Toggle completion status
- **Delete**: Remove todo items

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/todo-app.git
```

2. Open `index.html` in your browser or use Live Server.
